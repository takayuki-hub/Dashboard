# TASK-0011: E2Eテスト（Firebase Console検証）

**作成日**: 2026-09-14
**フェーズ**: Phase 4 - テスト・検証
**タイプ**: DIRECT（直接実装）
**工数見積**: 8時間
**依存タスク**: TASK-0010

## 概要

Firebase Analytics統合の完全なEnd-to-Endテストを実施します。実際のデバイス/エミュレータでアプリを動作させ、Firebase Console（DebugViewおよびリアルタイムイベント）でイベントとユーザープロパティが正しく記録されていることを確認します。本タスクでは、リリースビルドAPKを作成し、本番環境に近い条件でAnalyticsの動作を検証します。

## 目的

- Firebase Analyticsが実環境で正しく動作することを確認
- イベントがFirebase Consoleに正しく送信されることを検証
- ユーザープロパティが正しく記録されることを確認
- リアルタイムイベント検証でデータの整合性を保証

## 受け入れ基準

- [ ] Firebase DebugViewが正しく設定されている
- [ ] リリースビルドAPKが作成されている
- [ ] デバイス/エミュレータでアプリが正常に動作している
- [ ] `app_open`イベントがFirebase Consoleに記録されている
- [ ] `screen_view`イベントが全画面で記録されている
- [ ] タスク操作イベント（`task_create_clicked`, `task_edited`, `task_deleted`）が記録されている
- [ ] エラーイベント（`weather_fetch_failed`等）が記録されている
- [ ] ユーザープロパティ（`app_version`, `first_open_time`）が記録されている
- [ ] リアルタイムイベント検証で最新30分以内のイベントが確認できている
- [ ] 検証結果をドキュメント化している

## 技術仕様

### 環境構成

#### デバイス要件

- **物理デバイス**: Android 7.0以上（Min SDK 24）
- **エミュレータ**: Android Studio AVD（推奨: Pixel 6, Android 13）
- **ネットワーク**: インターネット接続必須（Firebase Consoleとの通信）

#### Firebase Console要件

- **プロジェクト**: dashboard-2fcc1
- **DebugView**: 有効化必須
- **Analytics**: Google Analyticsリンク有効

### 検証ツール

1. **Firebase Console DebugView**
   - URL: https://console.firebase.google.com/project/dashboard-2fcc1/analytics/debugview
   - 用途: リアルタイムイベント確認（最新60秒）

2. **Firebase Console Events**
   - URL: https://console.firebase.google.com/project/dashboard-2fcc1/analytics/events
   - 用途: 過去30日間のイベント集計確認

3. **Firebase Console User Properties**
   - URL: https://console.firebase.google.com/project/dashboard-2fcc1/analytics/user-properties
   - 用途: ユーザープロパティ確認

4. **adb logcat**
   - コマンド: `adb logcat | grep -i firebase`
   - 用途: ローカルログ確認

## 実装手順

### ステップ1: Firebase DebugView設定（30分）

#### 1-1. DebugView有効化

```bash
# アプリケーションIDを確認
adb shell pm list packages | grep dashboard

# DebugView有効化（デバイスが接続された状態で実行）
adb shell setprop debug.firebase.analytics.app com.github.takayuki_hub.dashboard

# 設定確認
adb shell getprop debug.firebase.analytics.app
# 出力: com.github.takayuki_hub.dashboard
```

**信頼性レベル**: 🔵 青信号（Firebase公式ドキュメントより）

#### 1-2. Firebase Consoleでの確認

1. https://console.firebase.google.com/project/dashboard-2fcc1/analytics/debugview を開く
2. デバイス名が表示されることを確認
3. DebugViewが「有効」状態であることを確認

**信頼性レベル**: 🔵 青信号

### ステップ2: リリースビルドAPK作成（1時間）

#### 2-1. google-services.jsonの配置確認

```bash
# google-services.jsonが存在することを確認
ls -l app/google-services.json

# .gitignoreに追加されていることを確認
grep google-services.json app/.gitignore
```

**期待される出力**:
```
-rw-r--r--  1 user  staff  1234 Sep 12 00:00 app/google-services.json
google-services.json
```

**信頼性レベル**: 🔵 青信号（要件REQ-401より）

#### 2-2. リリースビルド作成

```bash
# クリーンビルド
./gradlew clean

# リリースビルドAPK作成
./gradlew assembleRelease

# APKの存在確認
ls -lh app/build/outputs/apk/release/
```

**期待される出力**:
```
-rw-r--r--  1 user  staff   15M Sep 14 10:00 app-release-unsigned.apk
```

**注意**: リリースビルドでは、Firebase Analyticsが有効化されます（`BuildConfig.DEBUG == false`）。

**信頼性レベル**: 🔵 青信号（要件REQ-301より）

#### 2-3. APKのインストール

```bash
# APKをデバイス/エミュレータにインストール
adb install -r app/build/outputs/apk/release/app-release-unsigned.apk

# インストール確認
adb shell pm list packages | grep dashboard
```

**期待される出力**:
```
package:com.github.takayuki_hub.dashboard
```

**信頼性レベル**: 🔵 青信号

### ステップ3: アプリ起動・基本動作確認（30分）


**期待される出力**:

## トラブルシューティング

### イベントがDebugViewに表示されない

**原因**:
- DebugViewが有効化されていない
- デバイスがインターネットに接続されていない
- Firebase Analyticsが無効化されている（デバッグビルド）

**対処法**:
```bash
# DebugView再設定
adb shell setprop debug.firebase.analytics.app com.github.takayuki_hub.dashboard

# リリースビルドであることを確認
adb logcat | grep "MainApplication"
# 出力に "Firebase Analytics enabled" が含まれることを確認
```

### ユーザープロパティが表示されない

**原因**:
- プロパティ反映に時間がかかる（最大24時間）

**対処法**:
- 翌日再度確認
- DebugViewではなく、Eventsページで確認

## 注意事項

1. **リリースビルド必須**: デバッグビルドではAnalyticsが無効化されているため、必ずリリースビルドを使用

3. **イベント反映時間**: DebugViewはリアルタイムだが、Eventsページへの反映は数時間かかる場合がある
4. **プライバシー**: テストデータに個人情報を含めないこと
