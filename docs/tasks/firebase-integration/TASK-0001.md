#### 1.2 `core/analytics/build.gradle.kts` の作成

```kotlin
plugins {
    alias(libs.plugins.android.library)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.ksp)
    alias(libs.plugins.hilt)
}

android {
    namespace = "com.github.takayuki_hub.dashboard.core.analytics"
    compileSdk = 37

    defaultConfig {
        minSdk = 24
        targetSdk = 36

        testInstrumentationRunner = "androidx.test.runner.AndroidJUnitRunner"
        consumerProguardFiles("consumer-rules.pro")
    }

    buildTypes {
        release {
            isMinifyEnabled = false
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }

    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_11
        targetCompatibility = JavaVersion.VERSION_11
    }

    kotlinOptions {
        jvmTarget = "11"
    }
}

dependencies {
    // Firebase BOM
    implementation(platform(libs.firebase.bom))
    implementation(libs.firebase.analytics)

    // Hilt
    implementation(libs.hilt.android)
    ksp(libs.hilt.compiler)

    // Coroutines
    implementation(libs.kotlinx.coroutines.android)
    implementation(libs.kotlinx.coroutines.core)

    // Testing
    testImplementation(libs.junit)
    testImplementation(libs.mockito.core)
    testImplementation(libs.kotlinx.coroutines.test)
    androidTestImplementation(libs.androidx.test.ext.junit)
    androidTestImplementation(libs.androidx.test.espresso.core)
}
```

## 技術的注意事項

### ビルド設定

1. **Firebase BOM**: 既存のBOMバージョン（34.19.0）を使用することで、Firebase Analyticsのバージョン管理を一元化
2. **Min SDK**: 既存のプロジェクト設定（SDK 24）に合わせる
3. **Compile SDK**: 既存のプロジェクト設定（SDK 37 preview）に合わせる
4. **Java Version**: 既存のプロジェクト設定（Java 11）に合わせる

### モジュール依存

1. **Hilt**: KSPプロセッサを使用してコード生成を行う
2. **Coroutines**: 非同期処理のためにCoroutinesを使用
3. **Feature依存**: 各featureモジュールから`:core:analytics`を参照可能にする

### Gradleプラグイン

必要なGradleプラグイン（既存定義済み）：
- `com.android.library`
- `org.jetbrains.kotlin.android`
- `com.google.devtools.ksp`
- `com.google.dagger.hilt.android`

### KSP生成コード

Hilt依存を追加したため、KSP生成コードの問題が発生する可能性があります。以下のコマンドで解決できます：

```bash
./gradlew kspDebugKotlin
```

## トラブルシューティング

### 想定される問題と対処法

#### 1. Gradle Syncエラー

**問題**: Firebase BOMのバージョン競合
**対処法**: 既存の`gradle/libs.versions.toml`のFirebase BOMバージョンを確認し、整合性を保つ

#### 2. KSPエラー

**問題**: Hiltのコード生成エラー
**対処法**: `./gradlew clean && ./gradlew kspDebugKotlin`を実行

#### 3. モジュール認識エラー

**問題**: Android Studioが`:core:analytics`を認識しない
**対処法**:
1. `settings.gradle.kts`の記述を確認
2. Android Studioを再起動
3. `File > Invalidate Caches / Restart...`を実行

#### 4. 依存関係エラー

**問題**: Featureモジュールから`:core:analytics`をimportできない
**対処法**:
1. 各featureモジュールの`build.gradle.kts`に`implementation(project(":core:analytics"))`が追加されているか確認
2. Gradle Syncを実行
