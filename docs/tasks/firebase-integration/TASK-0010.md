## 概要

Firebase Analytics統合の統合テストを実装します。各featureモジュールのViewModelがAnalyticsRepositoryを正しく呼び出し、適切なイベントとパラメータを記録していることを検証します。Mock AnalyticsRepositoryを使用してテストを実施し、Firebase SDKへの実際の通信は行わずに動作を確認します。

- ViewModelとAnalyticsRepositoryの統合が正しく機能することを確認
- イベント記録の呼び出しが期待通り行われることを検証

- リグレッション防止のためのテストスイート構築

#### 1. HomeViewModelテスト

**ファイル**: `feature/home/src/test/java/com/github/takayuki_hub/dashboard/feature/home/ui/HomeViewModelTest.kt`

**テストケース**:
- `onScreenVisible_logsScreenViewEvent`
- `onTaskCreateClicked_logsTaskCreateEvent`
- `onWeatherRefresh_logsWeatherRefreshEvent`

**実装例**:

```kotlin
package com.github.takayuki_hub.dashboard.feature.home.ui

import com.github.takayuki_hub.dashboard.core.analytics.constants.AnalyticsEvents
import com.github.takayuki_hub.dashboard.core.analytics.constants.AnalyticsParams
import com.github.takayuki_hub.dashboard.core.analytics.repository.AnalyticsRepository
import io.mockk.coVerify
import io.mockk.mockk
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.ExperimentalCoroutinesApi
import kotlinx.coroutines.test.StandardTestDispatcher
import kotlinx.coroutines.test.resetMain
import kotlinx.coroutines.test.runTest
import kotlinx.coroutines.test.setMain
import org.junit.After
import org.junit.Before
import org.junit.Test

@OptIn(ExperimentalCoroutinesApi::class)
class HomeViewModelTest {

    private lateinit var analyticsRepository: AnalyticsRepository
    private lateinit var viewModel: HomeViewModel
    private val testDispatcher = StandardTestDispatcher()

    @Before
    fun setup() {
        Dispatchers.setMain(testDispatcher)
        analyticsRepository = mockk(relaxed = true)
        // 他の依存関係をモック化
        viewModel = HomeViewModel(
            analyticsRepository = analyticsRepository,
            // 他の依存関係...
        )
    }

    @After
    fun tearDown() {
        Dispatchers.resetMain()
    }

    @Test
    fun `onScreenVisible logs screen_view event`() = runTest {
        // When
        viewModel.onScreenVisible()
        testDispatcher.scheduler.advanceUntilIdle()

        // Then
        coVerify(exactly = 1) {
            analyticsRepository.logScreenView(
                screenName = AnalyticsEvents.SCREEN_HOME
            )
        }
    }

    @Test
    fun `onTaskCreateClicked logs task_create_clicked event`() = runTest {
        // When
        viewModel.onTaskCreateClicked()
        testDispatcher.scheduler.advanceUntilIdle()

        // Then
        coVerify(exactly = 1) {
            analyticsRepository.logEvent(
                eventName = AnalyticsEvents.TASK_CREATE_CLICKED,
                params = emptyMap()
            )
        }
    }
}
```

**信頼性レベル**: 🔵 青信号（要件定義REQ-201, REQ-202より）

**実装例**:

```kotlin
@Test
fun `fetchWeather failure logs weather_fetch_failed event with error details`() = runTest {
    // Given
    val exception = IOException("Network error")
    // weatherRepositoryがexceptionを返すようにモック設定

    // When
    viewModel.fetchWeather()
    testDispatcher.scheduler.advanceUntilIdle()

    // Then
    coVerify(exactly = 1) {
        analyticsRepository.logEvent(
            eventName = AnalyticsEvents.WEATHER_FETCH_FAILED,
            params = match { params ->
                params[AnalyticsParams.ERROR_TYPE] == "IOException" &&
                params[AnalyticsParams.ERROR_MESSAGE] == "Network error"
            }
        )
    }
}
```
