## ヒアリング結果サマリー

### 確認できた事項
- Firebase導入の主目的は「Analytics強化」（ユーザー行動分析・イベントトラッキング）
- `:core:analytics`モジュールを新規作成し、全featureから利用可能にする
- Repositoryパターン + Hilt DIによる実装
- 自動初期化を継続（明示的初期化コード不要）
- 包括的なイベントトラッキング（画面遷移、ユーザー操作、エラー、ライフサイクル）
- ユーザープロパティの記録機能が必要
- デバッグビルドでは基本的にアナリティクスを無効化
- 優先度は Should Have（推奨だが必須ではない）

### 追加/変更要件
- `:core:analytics`モジュールの新規作成
- `AnalyticsRepository`インターフェースと実装の作成
- `google-services.json`を`.gitignore`に追加
- 4種類のイベントカテゴリ（画面遷移、ユーザー操作、エラー、ライフサイクル）の実装
- ユーザープロパティ設定機能の実装
- デバッグビルド時の無効化設定

### 残課題
- 具体的なイベント名とパラメータの詳細仕様（実装フェーズで定義）
- ユーザープロパティの具体的な項目（実装フェーズで定義）
- パフォーマンス影響の測定方法
